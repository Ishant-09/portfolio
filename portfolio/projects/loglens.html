LogLens

Exploring memory-efficient log streaming, regex token extraction, and CLI diagnostics in Python.

Problem & Motivation

When debugging backend servers or local network daemons, raw logs arrive as dense, unformatted walls of text. Grepping through gigabytes of logs often leads to cognitive fatigue or slow system responses when reading large files directly into memory.

LogLens started as an exercise in Python fundamentals: how to efficiently stream files line-by-line using generators, parse varied timestamp formats, detect anomalous spikes, and output structured, human-readable data on the terminal.

Technical Architecture

The project focuses on three distinct layers:

  • Streaming Ingestion: Python generator expressions (`yield`) ensure the tool never loads entire multi-gigabyte log files into RAM at once.
  • Configurable Tokenizer: Compiling regular expressions once (`re.compile`) to tokenize syslog, Apache/Nginx, and custom JSON log structures.
  • Terminal Presentation: ANSI escape colorization for highlighting severity levels (`INFO`, `WARN`, `ERROR`, `FATAL`) with clean column alignment.
# Conceptual core: Streaming line parser with generator
import re
from typing import Generator, Dict, Any

LOG_PATTERN = re.compile(
    r'^\[(?P<timestamp>.*?)\]\s+\[(?P<level>\w+)\]\s+(?P<message>.*)$'
)

def stream_and_parse(file_path: str) -> Generator[Dict[str, Any], None, None]:
    with open(file_path, 'r', encoding='utf-8', errors='replace') as stream:
        for line_num, line in enumerate(stream, start=1):
            match = LOG_PATTERN.match(line.strip())
            if match:
                record = match.groupdict()
                record['line'] = line_num
                yield record

What I Learned So Far

1. Memory Management in Python: Understanding the difference between `read()`, `readlines()`, and iterator-based streaming.

2. Regex Performance: Precompiling patterns and avoiding catastrophic backtracking when parsing malformed or truncated log lines.

3. Terminal UX: Designing clear CLI argument flags with Python's built-in `argparse` module.

Current Status & Next Steps

The core parsing logic is working in small local scripts. The next phase involves adding real-time file following (`tail -f` simulation) and JSON output formatting for piping into downstream tools.
