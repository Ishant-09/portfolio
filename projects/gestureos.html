GestureOS

Investigating touchless spatial human-computer interaction using OpenCV frame capture and MediaPipe hand landmark tracking.

Problem & Motivation

Standard computer interactions rely heavily on physical mice, trackpads, and keyboards. While precise, there are scenarios—such as displaying slides during a presentation, browsing recipes with dirty hands in a kitchen, or accessibility setups—where touchless spatial gestures provide an ergonomic alternative.

GestureOS is an exploration into how modern computer vision algorithms can translate webcam video frames into discrete, noise-filtered OS virtual inputs without requiring specialized depth cameras or wearable sensors.

Technical Architecture

The pipeline operates sequentially on incoming video streams:

  • Frame Acquisition: OpenCV captures frames from the default webcam at 30 FPS, converts the BGR color space to RGB, and flips horizontally for mirror intuition.
  • Landmark Extraction: MediaPipe Hands extracts 21 three-dimensional landmark points (X, Y, Z normalized coordinates) corresponding to knuckle joints, wrists, and fingertips.
  • Gesture Classification & Smoothing: Calculating Euclidean distances between index finger tip (landmark 8) and thumb tip (landmark 4). Applying an Exponential Moving Average (EMA) filter to dampen jitter before dispatching clicks.
# Conceptual pipeline: Landmark Euclidean distance trigger
import math

def calculate_pinch_distance(p1, p2, width, height) -> float:
    # Scale normalized coordinates to actual pixel space
    x1, y1 = int(p1.x * width), int(p1.y * height)
    x2, y2 = int(p2.x * width), int(p2.y * height)
    # Euclidean distance
    return math.hypot(x2 - x1, y2 - y1)

# Threshold comparison: distance < 30px indicates a pinch gesture

What I'm Learning

1. Real-time Latency: Frame processing must stay under ~33 milliseconds to maintain a responsive 30 FPS tracking experience.

2. Coordinate Normalization: Mapping camera sensor coordinates to desktop screen resolutions while accounting for aspect ratios and dead-zones.

3. Noise & Jitter Suppression: Raw computer vision landmark coordinates fluctuate naturally due to lighting noise; software smoothing is mandatory to prevent accidental clicks.

Current Status

This is an exploratory research project. Basic landmark extraction and pinch detection work reliably in controlled indoor lighting. Current research focuses on multi-gesture differentiation (e.g. scroll vs. drag).
